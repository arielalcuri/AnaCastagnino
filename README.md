# Castagnino Sá & Asociados | Estudio Jurídico

Sitio web oficial del Estudio Jurídico **Castagnino Sá & Asociados**, especializado en asesoramiento societario y regularización ante los organismos de control **IGJ** (Inspección General de Justicia) y **DPPJ** (Dirección de Personas Jurídicas) en Argentina.

## 🚀 Características
- **Optimización de Carga**: Implementación de preloads y optimización de imágenes para una navegación fluida.
- **Diseño Premium**: Interfaz moderna y profesional adaptada a la identidad del estudio.
- **Responsive**: Totalmente adaptable a dispositivos móviles y tablets.
- **Integración de Contacto**: Formulario funcional y acceso directo a WhatsApp y LinkedIn.

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 (Variables y Grillas)
- JavaScript (Vanilla)
- Google Fonts (Cinzel & Lato)

## 📁 Estructura del Proyecto
- `/castagnino-sa'sociados`: Directorio principal del sitio web (HTML, CSS, JS).
